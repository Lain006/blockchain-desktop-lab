# 关键操作流程

| 触发与前提 | 经过的边界 | 成功结果 | 拒绝/失败情况 |
|---|---|---|---|
| 点击挖矿，目标在线 | renderer → 白名单 IPC → 节点独立进程 → 真实 PoW → 追加 → 广播 | 文件写入成功后提交，接收方独立验证并保存 | 非文本/不合法块拒绝；写入失败不提交 |
| 新建节点 | 管理器创建独立进程和稳定 ID | 独立创世链，可连接同步 | 端口已占用时报错，桌面自动换空闲端口 |
| 连接节点 | 受限 IPC → TCP → 课程握手及链验证 | 直接连接建立，验证后的区块可交换 | 不可访问、非法端口、非法消息被拒绝；连接不代表全网拓扑 |
| 停止节点 | 管理器 → 节点关闭监听和连接 | 停止进程，文件和恢复配置保留 | 配置保存失败会报错 |
| 打开网页 | 管理器只读目录 → 节点 GET API → 前端解析 | 展示真实状态与采样时间 | 错误保留过期快照并标明错误，不用假数据补齐 |

没有删单个历史区块的接口。关闭软件保存恢复，重建实验须先备份完整数据目录。
