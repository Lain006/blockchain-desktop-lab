# 验证与已知限制

## 已有自动化覆盖

| 规则 | 验证入口 | 成功与负面情况 |
|---|---|---|
| 哈希与共识 | blockchaindemo/test-blockchain.js、test-regressions.js | 真实挖矿、创世与后续校验、篡改/等长/短链拒绝、快照隔离 |
| 消息与P2P | test-messages.js、test-p2p.js | 真实本机 TCP、握手、拆包粘包、中文、非法消息隔离 |
| CLI/HTTP | test-cli.js | 两进程挖矿同步、目录读写边界、参数拒绝、端口占用恢复与退出 |
| 前端逻辑 | frontend/tests | 真实字段解析、轮询取消、失败快照、旧缓存迁移 |
| 网页操作 | npm run test:e2e | 本机Edge、真实后端、五宽度、节点目录变化、追加与错误恢复 |
| 图文步骤 | npm run docs:screenshots | 独立实验下Electron按钮全过程，保存恢复及多节点 |
| 桌面持久化与进程 | npm test / npm run test:desktop | 写入失败不提交、损坏备份恢复、真实三进程转发、端口冲突、窗口按钮、退出和恢复 |

公开副本重新进行依赖安装、类型检查、构建、上述相关测试；执行结果以仓库 Actions 和发布记录为准，不把“有测试文件”当成远程 CI 已经通过。

## 建议的手工验收

在第二台无项目缓存的 Windows 电脑从 README 首次安装/解压，逐项确认操作路径和提示。使用真实键盘、屏幕阅读器检查可访问性。确认默认浏览器和数据目录按钮能打开本机目标。

## 未覆盖/不承诺

跨电脑 P2P、公网部署、长时间压力、物理手机、所有浏览器、断电级持久化耐久性、老师人工验收。Windows解压软件未做代码签名；本机限制PATH验证不是另一台干净电脑实测。

截图和演示测试数据只在测试/教程里生成；应用首次不自动制造演示区块。记录的历史基线与本次依赖安全维护差异见版本来源文件。
