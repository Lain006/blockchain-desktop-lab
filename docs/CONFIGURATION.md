# 配置与端口

| 名称 | 使用位置 | 来源/作用 | 隐私及操作提醒 |
|---|---|---|---|
| VITE_NODE_API_URL | 前端，公开构建参数 | 手动 Vite 启动/构建前设置，默认 http://127.0.0.1:3001 | 不是 secret；不能填带凭据的地址 |
| window.__NODE_API_URL__ | 桌面观测页面 | 服务端注入当前目录服务 origin，优先于 Vite 参数 | 用当前客户端打开网页，不看另一套旧标签 |
| PLAYWRIGHT_CHANNEL | 截图脚本 | 默认 msedge，可选本机其他已安装 Chromium 渠道 | 自动化工具参数，不进入业务数据 |
| --lab-data-dir=... | 桌面测试启动 | 独立测试用户数据目录 | 仅测试/排障，不能覆盖真实实验；退出后测试清理自己的临时目录 |
| ELECTRON_MIRROR | 构建/源码启动 | 可指定运行环境镜像；正常使用无需设置 | 程序不硬编码本机代理 |

没有 API key、密码或第三方付费服务配置。更改 Vite 环境参数必须在同一终端重新启动/构建；PowerShell 与 CMD 语法见主 README。

公开发布前核对：提交清单不包含用户数据/凭据；监听保持127.0.0.1；说明测试边界；核对截图来自隔离样例；不把测试路径写入公开日志。
